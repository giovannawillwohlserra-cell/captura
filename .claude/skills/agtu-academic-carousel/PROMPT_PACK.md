## 11. PROMPT — MODO EDITORIAL AGTU

Antes de escrever qualquer conteúdo para a AGTU, faça internamente estas perguntas:

1. Qual transformação do mundo profissional estamos mostrando?
2. Por que isso importa para alguém com 35-50 anos?
3. Qual competência essa mudança valoriza?
4. Existe uma lacuna entre o que o profissional sabe hoje e o que o mercado começa a exigir?
5. Como a educação superior pode preencher essa lacuna?
6. O conteúdo parece uma análise universitária ou uma propaganda?
7. O leitor teria vontade de salvar ou compartilhar?

Só então escreva o carrossel.

# REGRAS VISUAIS PARA O DESIGNER

Formato recomendado: 1080 × 1350 px (4:5).

Pensar o carrossel como uma única peça editorial, não como 5 artes independentes.

Hierarquia:
1. headline;
2. informação-chave;
3. detalhe/contexto;
4. elemento visual.

Evitar:
- excesso de texto;
- 5 fontes diferentes;
- excesso de ícones;
- visual genérico de "IA";
- banco de imagens óbvio;
- estética de infoproduto;
- excesso de gradientes;
- aparência de anúncio.

Priorizar:
- tipografia forte;
- espaço negativo;
- ritmo visual;
- elementos editoriais;
- números/dados quando existirem;
- fotografia real quando houver pessoas;
- consistência entre telas.

Para temas de tecnologia/IA, evitar que toda peça seja azul e futurista. A AGTU deve parecer universidade, não startup de IA.

# MATRIZ DE CTA

TOPO:
"Salve para acompanhar essa discussão."

MEIO:
"Você já percebeu essa mudança na sua área?"

FUNDO:
"Quer conhecer a formação que prepara profissionais para esse cenário? Comente [PALAVRA]."

"Comente [PALAVRA] e receba a grade."

Nunca usar CTA incompatível com a intenção do conteúdo.
