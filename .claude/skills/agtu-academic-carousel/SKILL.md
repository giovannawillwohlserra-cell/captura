# AGTU Academic Carousel Skill

## Objetivo
Criar conteúdo de Instagram que:
1. pare o scroll;
2. ensine algo relevante;
3. conecte a mudança do mercado à carreira;
4. faça o leitor perceber uma lacuna de conhecimento;
5. conduza naturalmente à formação acadêmica;
6. preserve autoridade universitária e não pareça anúncio de curso.

## Público
Profissionais de 35-50 anos, já inseridos no mercado, que buscam graduação, mestrado ou doutorado para atualização, progressão profissional, mudança de área ou diferenciação.

## Voz
- acadêmica, contemporânea e segura;
- inteligente sem ser rebuscada;
- profissional, madura e humana;
- direta;
- sem clichês de marketing;
- sem excesso de emojis;
- sem "revolucione sua carreira", "desbloqueie seu potencial", "o futuro chegou";
- não infantilizar o leitor;
- não escrever como influencer de tecnologia.

## Regra central
O carrossel não deve explicar tudo. Deve criar uma sequência de descoberta:
HOOK → CONTEXTO → IMPACTO → IMPLICAÇÃO PROFISSIONAL → LACUNA DE COMPETÊNCIA → CTA.

## Regra de tela
- 1 ideia principal por tela.
- Preferir 8-25 palavras por tela.
- Frases curtas.
- Evitar parágrafos.
- Se uma tela precisar de muita explicação, dividir ou mover contexto para a legenda.
- A capa deve funcionar mesmo sem a legenda.
- A última tela deve deixar clara a próxima ação.

## Funil
TOPO: curiosidade + descoberta.
MEIO: interpretação + aplicação profissional.
FUNDO: mostrar a competência que o mercado começa a exigir e conectar essa lacuna à formação acadêmica.
CTA: curso/programa/grade/consultoria de admissão, conforme objetivo.

## Estruturas prioritárias
1. Tendência → "Isso está acontecendo" → "Isso muda X" → "Isso exige Y" → formação.
2. Contrarian → crença comum → por que está incompleta → nova perspectiva → competência.
3. Problem-solution → problema profissional → consequência → framework → CTA.
4. Career gap → habilidade atual → nova exigência → risco de ficar para trás → formação.
5. Explainer → conceito → exemplo → aplicação → implicação para carreira.
6. Myth vs reality → mito → realidade → evidência → o que fazer.
7. Data story → dado → interpretação → impacto → oportunidade.
8. Case/market shift → acontecimento → por que importa → quem será afetado → preparação.

## Critério de qualidade
Antes de entregar, verificar:
- A capa cria curiosidade sem clickbait?
- Cada swipe acrescenta algo?
- Existe uma mudança de percepção no meio?
- O público consegue se enxergar no problema?
- A formação aparece como consequência lógica, não como propaganda?
- O texto cabe em uma tela de celular?
- A legenda complementa, em vez de repetir?
- Existe um CTA mensurável?
