# AGTU Content System — Carrosséis Acadêmicos

Pack criado para produção de conteúdo de Instagram da AGTU.

Arquivos:
- SKILL.md — skill principal para usar em um agente/Claude/ambiente de skills.
- PROMPT_PACK.md — prompts prontos para estratégia, copy, revisão e fundo de funil.

Base estratégica:
- carrossel como narrativa;
- uma ideia por tela;
- hook específico;
- conteúdo educacional que gera salvamento/compartilhamento;
- conexão entre tendência, carreira e competência;
- formação acadêmica como consequência da narrativa, não como anúncio.

O material foi construído considerando práticas de Instagram observadas em 2026 e referências de comunicação de universidades.
